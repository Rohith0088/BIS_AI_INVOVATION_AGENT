# BIS Detailed Material, Product, and Certification Dataset

This package contains official BIS register extractions accessed on 28 August 2026. Scheme I and Scheme II rows are taken from the BIS compulsory-certification pages. Scheme X rows include the available electrical-equipment and machinery-scope tables. Scheme IV includes its listed CoC products. The certification process CSV provides a detailed generic workflow; product-specific QCOs, product manuals, amendments, fees, and portal rules must be checked for the exact product before operational use.

The term ISI mark is not universal for every manufactured raw material. A product requires a BIS mark or certificate only when the applicable government notification/QCO or BIS scheme requires it. The dataset preserves the scheme and marking route so an agent can distinguish ISI, CRS Registration Mark, Scheme X, CoC, and hallmarking.
